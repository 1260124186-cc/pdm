Detect when the saved Python interpreter no longer exists and converge the stale binding in one pass: clear the project pointer, prune broken `use_cache.json` entries and drop an unsatisfiable `.python-version` pin, then rebind to another interpreter satisfying `requires-python`. Valid manual environments are never removed; when no interpreter matches, a clear error is raised and the project is left in a retryable state instead of being pointed at a wrong version.
